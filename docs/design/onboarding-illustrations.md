# Ilustraciones de preferencias

Generadas con la herramienta integrada `image_gen` para el onboarding de PROXVEL. Son escenas conceptuales para representar intereses; no son fotografías documentales. Los originales se conservan en el directorio de imágenes generadas de Codex.

Los archivos finales están en `assets/images/onboarding_<nombre>_scene.webp`, a 512 × 512 píxeles, WebP calidad 86. Se muestran con recorte circular y selección violeta (`AppColors.discovery`). Las imágenes de relax, urbano y cultura se reutilizan para las tres opciones de ambiente.

## Prompts finales

### nature

Archivo: `assets/images/onboarding_nature_scene.webp`

Use case: illustration-story. Create ONE square full-bleed illustration asset for the nature interest option in a Peruvian travel app. Subject: A lush Peruvian Amazon river bend with a small waterfall, tropical foliage and distant emerald hills. No people. Style: beautiful clean 2D animated travel illustration, flat geometric painted shapes with gentle gradients, like modern premium mobile onboarding illustrations. Not photorealistic, not 3D, no UI. Cheerful refined palette, turquoise, forest green, pale lavender skies, coral and warm yellow accents. Composition: single clear scene with the main subject centered within the central 70% so it remains recognizable inside a circular crop. Landscape/environment fills all four edges, no border, no circular frame, no text, letters, symbols, labels or watermark. High clarity at small thumbnail sizes. Output square.
